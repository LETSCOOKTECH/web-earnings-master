# Niche research: demand before code

## Trigger
New site idea, market expansion, new converter type, product feature prioritization, or a keyword opportunity claim.

## Method
1. Define user job-to-be-done and expected useful output (e.g. batch resize 100 product images). Separate audience segment, country, device, one-time vs recurring demand.
2. Build exact and related non-branded queries in `templates/keyword-research.csv`: query, country, volume, date, source, CPC, organic difficulty, click potential, SERP features, intent, primary top-page, source URL, confidence.
3. Use Semrush/Ahrefs **actual exports if licensed**; never invent volume/KD. Google Keyword Planner estimates **advertiser** competition, not organic KD; Google Trends 0–100 scores are normalized, not monthly volume.
4. Inspect top results in US, GB, CA, AU, IN separately; capture SERP features, ad/AI occupancy, site authority, **page-level** references, age, helpfulness, exact task provided and visible weaknesses. Note search personalization/device/geography.
5. Examine historical seasonality; task frequency; likely click-through when zero-click answers are sufficient; mobile or desktop demand; premium traffic share for ad yield.
6. Determine how we acquire first users without SEO: creators, developers, support forums, integrations, GitHub, original experiments. Respect each community's self-promotion rules.
7. Compare marginal processing cost and abuse/hosting risk; estimate revenue only as labeled *scenarios*, never as promised RPMs.
8. Approve/reject in `templates/niche-decision.md`. Include what would change the decision, references and uncertainty.

## Non-negotiable gate
No full product build if exact-query demand, SERP feasibility or a credible independent acquisition channel is missing. A large competitor's TOTAL traffic does not equal reachable non-branded organic demand. Estimate traffic potential conservatively and clearly distinguish it from clicks.
