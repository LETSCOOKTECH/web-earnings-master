# web-app-store-discovery

**Trigger:** ASO, Google Play/App Store listing, mobile app search discovery, installs, store conversion, localization or website-vs-app distribution comparison.

**Read:** docs/foundations/07-aso-discovery.md, 08-experimental-reverse-engineering.md, 09-source-refresh.md and actual Google Play/Apple developer policy pages.

**Gate:** If no actual store app/listing exists, mark ASO not applicable and use SEO/vertical referral instead; PWA alone has no automatic store distribution.

**Method:**
1. Define platform, country, language, app category, user task, package ownership, listed app status and research window.
2. Verify latest store metadata policy and eligible ranking/discovery statements from first-party Google Play/Apple docs. Exact ranking weights are undisclosed.
3. Observe real store search results for user queries; identify paid placements, listing assets, functionality, ratings as authentic reputation, device compatibility and conversion friction.
4. Research target job vs currently distributed rivals; run authorized functional tests, not snippets-only feature assumptions. No fake ratings, fake downloads or trademark imitation.
5. Specify listing and product improvements, screenshots that truthfully match app, localized copy and reliability; monitor real store listing visitor -> install -> first value -> retention.
6. If using third-party estimates, label modeled. If Play Console/App Store Connect not connected, do not invent download or revenue data.

**Output:** dated store-search audit, exact listing optimization and quality gaps, acquisition/retention funnel and safe experiment, or explicit ASO scope exclusion for web-only product.

## Deep operations extension (v2.2)
Chapter 14 distinguishes web, local, media, partner and app-store indexes; chapter 17 describes cross-channel distribution constraints. If no actual published store app, mark Play/App Store ASO out of scope. For a real app, separate search impression, listing view, organic install, first-value completion, retention and monetization. Reopen current platform listing/store policy, experiment assets and actual country/device market; no invented store weight, download number or fake review manipulation.
