# Content And Image Seo

**Use when:** Create original high-value tool landing pages, troubleshooting guides, image/video assets, structured data and topical internal links without scaled-content abuse.

**Workflow contract:** Follow the next steps proportionally to the request. Prefer current primary sources to saved claims. Adapt the sequence when evidence suggests a better route; do not overbuild a minor task. Show exact verification, uncertainty, and safety boundaries. Read `AGENTS.md` and the matching `references/` files when carrying out substantial work.

## Content that users and search can actually use
1. Make the interactive tool immediately useful: H1, plain capability statement, controls, limits, inputs and outputs; avoid forcing an article before the utility.
2. Place original explanatory material around real product questions: supported formats, accuracy/method, examples, comparison, limitations, failures and fixes. Keep length proportional to user need; no required magic 1000-word quota.
3. Test and document methodology before publishing benchmark figures. Include data origin/licenses, test devices/browsers, software versions, input fixtures, timing, error cases and any biased conditions.
4. Use HTML semantics, headings to organize facts, real tables, descriptive outbound references to first-party technical specs when applicable, and purposeful internal anchors linking next tasks.
5. Create original before/after images, video demonstrations and step-by-step illustrations when they genuinely help. Use proper `img src`, alt text, dimensions, modern formats and lazy-loading below fold; avoid watermarks, copyright infringement and synthetic fake proof.
6. No doorway pages, mass AI paraphrases, keyword variation pages, hidden content, fabricated testimonials, fake schema ratings or published experiments that never ran.
7. Use accurate `WebApplication`/`SoftwareApplication`, `BreadcrumbList`, `Organization` and article markup only when applicable; Google feature eligibility needs feature-specific validation.
8. Update guides for genuine product or standards changes; record `lastmod` for substantive changes only. Track Search Console query/page performance and human conversions to decide edits.
9. International localization must be reviewed by a fluent speaker/competent checker; correct regional specifications and `hreflang` alternatives only if real.

## Deliverable
High-value page brief (`templates/high-value-page-brief.md`) including source evidence, UX, search intent, schema and validation steps. A published page is not automatically indexed.
