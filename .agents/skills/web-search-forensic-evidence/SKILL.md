# WEB SEARCH FORENSIC EVIDENCE

**Trigger:** Search algorithm teardown, ranking diagram, Google leak, NavBoost/Glue/Trawler/RankEmbedBERT/Q-star, patents, traffic collapse or purported hidden signals.

**Routing:** Owner: trace claims and trust boundaries; web-technical-seo implements proven crawl controls, web-generative-engine-optimization implements provider-specific AI citation experiments.

**Source and uncertainty policy:** Treat user-uploaded diagrams as user hypotheses, not private Google proof. Reopen original provider sources before deployment. Distinguish code/fixture evidence from live crawlers, publisher accounts, traffic and revenue.

## End-to-end execution contract
1. Parse each assertion into a single falsifiable claim; preserve exact wording, original document/page or upload line, claimed provider scope, date and suggested intervention.
2. Classify FIRST_PARTY_EXPLICIT, COURT_EVIDENCE, LEAKED_SCHEMA, RESEARCH_REPRODUCED, PATENT_POSSIBILITY, PROVIDER_CASE_STUDY, THIRD_PARTY_ESTIMATE, OBSERVATIONAL_CORRELATION, MODEL_ASSUMPTION or UNSUPPORTED.
3. Consult original federal-court exhibit or testimony for system names, but distinguish existence of Q*/P*/T*, Trawler, Ascorer, NavBoost or RankEmbedBERT from deployed weighting or a stable SEO formula.
4. Check the user's diagram step by step: crawl frontier → rendering → hybrid index → multi-stage ranking → SERP composition is a conceptual architecture, not a proven lossless description of every modern query path.
5. Verify official guidance before action: Google crawl/index docs, AI Search eligibility, spam policies, Search Console metrics, Bing Webmaster features, and provider crawler identity.
6. Require causal evidence: instrument intervention, negative controls, time/locale/device/query, indexing eligibility, page/job correctness and confounding factors; third-party Semrush/Ahrefs visits are estimates, not actual first-party user logs.
7. Reject guaranteed claims such as fixed NavBoost boosts from dwell time, ETag as mandatory ranking advantage, information-gain patents as verified production ranking, specific query-fan-out weights or 'best' framework based on CrUX selection bias.
8. Record false positives and docs changed since previous snapshot. Never infer Search ranking from Lighthouse agentic scores, llms.txt presence or a user-controlled search prompt.
9. Output dated claim ledger, source access scope, evidence gaps, production implications, reversible experiments, priority and no-go claims. Preserve original research as hypothesis even when rejecting unsupported causal claims.

## Non-negotiable FAIL / UNKNOWN gates
- No Google ranking weight may be invented from field name or search result.
- Patent is not production use; indexed excerpt is not original-body verification.
- A model assistant explaining why it cited a URL is not privileged disclosure of its actual retrieval pipeline.
- No traffic win is certified without site-owner impressions, ranking and meaningful human task completion.

## Required deliverables
- Scope and real user job, alternatives, testable acceptance contract and owner.
- Dated source ledger with exact URL, first-party versus excerpt status, evidence for each nontrivial claim.
- Reproducible tests or explicit NOT_RUN and UNKNOWN_EXTERNAL entries, including malicious/failure cases.
- Release decision, known risks, task economics, rollback, actual deployment and publisher/search evidence when authorized.
