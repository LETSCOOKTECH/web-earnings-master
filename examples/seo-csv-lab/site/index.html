How duplicates are detected

Records are compared cell by cell, with the first row optionally treated as headers. Commas inside quoted fields and escaped quotes are parsed before comparison. The tool does not remove partially similar records, and mismatched column counts cause an error.

Data integrity and safety

Only UTF-8 comma-separated values are supported, not XLSX or arbitrary legacy encodings. Blank single-column records are preserved. The spreadsheet-safety option escapes formula-like values beginning with dangerous operators, so turn it off only if you need unchanged raw data and understand spreadsheet injection risk. Signed numbers and scientific notation are preserved.
