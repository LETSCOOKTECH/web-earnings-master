# Sustainable discovery and authority

## Non-commodity outputs
- Document actual test methodology and licenses; publish benchmark results only from real files and reproducible steps.
- Make tool output explainable and exportable where safe; public sample files with consent/licensing.
- Support niche workflows e.g. creators batch-exporting web-ready assets rather than only generic input conversion.

## Organic acquisition
Pick 4–8 indexable core task URLs, not 100 template variants. Test current rankings vs relevant top-10 pages. Link organically between different tasks and actual guides, not keyword-stuffed anchors. Submit sitemaps and monitor GSC; no guaranteed discovery schedule.

## Distribution
Independent reference assets: GitHub source with proper licensing, screenshots, technical how-to demos, YouTube tutorials, partner embedding when economics allow, relevant genuine forum help, educators, communities. No link exchanges or spam, no paid links for ranking credit.

## AI visibility
Provide verifiable specific information; stable permalinks; descriptive code, table captions and accessible controls. Measure citations and actual AI-referral completions separately; avoid trying to optimize by manipulating prompt instructions on page.

## Outcome
Qualified human sessions, real tool starts/completions, error reduction, return usage and net earnings. Not total keyword count or bot visits.
