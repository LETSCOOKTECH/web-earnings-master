# AdSense — site eligibility, approval, invalid traffic, placements

**Source review 2026-11-22. Official status must be rechecked for every application.** Primary sources: `google-adsense-eligibility`, `google-adsense-site-ready`, `google-adsense-site-status`, `google-adsense-program`, `google-publisher-policies`, `google-ads-placement`, `google-inventory-no-content`, `google-adsense-cmp` in source registry.

## Actual obligations (not optional)
- Account: legal owner/payee eligibility (18+ for individual account; guardian route if minor), own/control site, verifiable site; accurate identity/payment info when required; avoid duplicate AdSense publisher account.
- Site: live, accessible to Google crawlers/review, functional, meaningful and original content, sensible navigation, policy-compliant inventory. Each domain must be added and approved (`Ready`) before Google ads serve.
- Content: no copied/scraped/copyright-violating work, illicit/harmful material, malware or automatically generated pages with little meaningful value. Site language must be supported for the applicable AdSense product.
- Traffic: only genuine human interest; prohibit paid invalid traffic, bots, click exchanges, incentivized clicks, misleading referrals, encouraging users to support by ad clicks, self-clicks.
- Advertisements: don't make ads look like Download, Next, Submit, Upload or Convert; avoid accidental clicks beside interactive controls; don't obscure UI or overload content; respect restrictions on pop-unders/windows and contextual ad environments; never ads on empty/low-publisher-content screens.
- Privacy: disclose advertising cookies, third-party tracking/data collection and users' options; implement legally valid notices and required certified CMP for applicable EEA/UK/Swiss Google advertising; test regional behavior. Other local laws can add obligations.
- Seller authorization: use real current seller ID(s), `ads.txt` crawled and consistent with authorized sellers once configured. Site verification can occur by methods other than ads.txt; do NOT invent a publisher ID.

## Not published as universal AdSense requirements
No globally fixed 10k traffic, 30 articles, 1000 words per page, 6-month-old domain, 100 backlinks, sitemap submission, exact framework, About/Terms page count. Meaningful author/operator transparency, privacy policy, contact, terms and original guides are strong **internal readiness gates**, not all standalone Google numeric mandates.

## Applying
1. Complete site with verifiable functionality and independent original content.
2. Real operator contact, accurate policy/consent and accessible public pages; test ads absent/clean during review.
3. Set up publisher account and add/verify each domain via real account-provided mechanism; request review; inspect rejection reasons.
4. Only display AdSense when status `Ready`; add accurate ads.txt; check page appearance, mobile ad density, consent and invalid-traffic reports.

## Site checklist
[ ] User can accomplish real work. [ ] Raw HTML meaningful. [ ] No blank ad-only screens. [ ] Real ad action separation. [ ] Consent and cookies disclosed. [ ] Legal rights to content. [ ] Verified site ownership. [ ] Ready status checked. [ ] Legitimate traffic. [ ] ads.txt correct if used. [ ] No unsafe third-party scripts.

## Important exception
Google allows other networks with AdSense in some configurations; **this does not mean every third-party ad format is compliant**. Always reconcile Google rules, provider tags, privacy and host terms before co-serving. See `references/monetag-and-networks.md`.
