# Astro code examples, not a complete deployed app
These are reusable **code templates** for the SEO architecture; they are not a substitute for the tested original image-processing project. `src/pages/tools/image-resizer.astro` contains explanatory placeholder text and **must not be launched as a functioning tool** until a working accessible island and output verification are integrated. Build and inspect the final generated HTML before making any SEO claim.

Install Astro and `@astrojs/sitemap` in the real application. Use actual SITE_URL. Merge templates into the project only after reviewing the current project dependencies. Check schema, Astro version, site URLs, sitemap index, robots, and canonical outputs. See `docs/SEARCH_ENGINEERING.md`.
