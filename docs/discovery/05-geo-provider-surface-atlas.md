# GEO provider surface atlas — not a universal "AI rank" checklist
**Reviewed:** 2026-11-23. **Structured index:** `sources/geo_provider_surface_atlas_2026-11-23.json`. 21 different products/surfaces; **8 provider retrieval sources explicitly UNKNOWN**. Each line is an investigative scope, NOT verified algorithm or complete first-party policy.

## The mechanism that must be identified first
Before claiming a page will appear "in AI", establish which consumer **product**, model/mode, geographic region, retrieval route, visible answer, indexing source, search crawler, training control and site-owner analytics are involved. A brand can expose a model via an app, API, assistant, search results and browser automation with **different retrieval rules**. No legitimate expert can infer a global citation-rank formula from the name of a model or a prompt.

## Group 1. Search-index-grounded generative responses
Google AI Overviews and AI Mode are search experiences. Index/snippet eligibility and property inclusion are inspectable; provider source selection is not. Bing Webmaster AI Performance provides citation/grounding evidence in a distinct reporting system. Brave Answer with AI uses Brave's search system and cites source links, while Brave's crawler lacks a distinct user-agent token according to its documentation. DuckDuckGo Search Assist combines search evidence using independent/partner sources. Baidu offers an AI traffic analytics interface to verified site owners. Each source and model has unique geography and measurement limitations.

## Group 2. Web assistants and user fetches
ChatGPT Search uses OAI-SearchBot for search crawling; GPTBot is model training and ChatGPT-User is user-triggered. Claude-SearchBot, ClaudeBot, Claude-User have separate roles. PerplexityBot supports search, Perplexity-User user activity. Kagi Assistant may incorporate Kagi Search with web access toggled; Kagi Search composes multiple sources and is not a fixed "Kagi-only crawler" assumption. Duck.ai chat is a distinct experience from DuckDuckGo Search Assist.

## Group 3. Modes for which provider evidence is missing
Current surface-specific website retrieval/index/citation controls were not established from original providers here for Yandex Alice, Naver AI, Meta AI, Grok, Qwen, DeepSeek, You.com or Apple Intelligence/Siri; the structured atlas marks each UNKNOWN. These products may have important features, but treating generic vendor/LLM descriptions as confirmed public SEO algorithms would be fabricated.

A proper module for one of these begins with identifying the exact product and country, original docs and public test route; only then add an official first-party claim, validated crawler access and account-defined citation metrics.

## Per-engine research record template (required)
1. provider, product, version/mode, subscription/locale/device/time.
2. search index ownership and partners explicitly stated in the official original, or UNKNOWN.
3. search crawler, training crawler, user request agent, WAF identity verification and opt-out controls (do not conflate).
4. source discovery/grounding behavior; exact disclosed versus inferred mechanisms and alternatives.
5. permitted query experiment: representative prompt list, repeat samples, logged time, citations/visible links and answer factual correctness.
6. independently observed website referral and human task completion, separated from bot requests and sampled citation observations.
7. owner analytics panel and metric definitions (e.g. GSC AI impressions, Bing Citation Share, Baidu AI traffic); mark unconnected accounts UNKNOWN.
8. country/rollout/effective date/version and change monitoring.
9. disproof criteria, provider limitations, links to actual original source bodies and best next experiment.
10. skill modification only after verified results; no guaranteed ranking/citation or magic files.

## Ranked work priority is about potential value, not a hidden provider factor
- **Tier A, most evidence-ready:** Google Search AI Mode/Overviews, ChatGPT Search, Claude Search, Perplexity, Bing AI/Copilot. Primary docs and established bot/analytics entry points.
- **Tier B, supported but different/search-source complexity:** Brave AI Answers, Kagi Assistant, DuckDuckGo Search Assist, Duck.ai, Baidu AI Search. Research exact index/crawler/analytics and test locally.
- **Tier C, provider source unverified:** Yandex Alice, Naver AI, Meta AI, Grok, Qwen, DeepSeek, You.com, Apple Intelligence; source-first research without fabricated weights or false negative "can't appear".

Even within Tier A, platform result changes, user intent, local SERP, prompt panel and actual task success decide whether investing is worthwhile. A source-citation test is not a measurement of SEO #1 or AdSense earnings.
