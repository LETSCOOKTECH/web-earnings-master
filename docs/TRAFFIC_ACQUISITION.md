# Actual traffic acquisition — repeatable playbook

## Relevance and distribution before page count
Launch one genuinely useful flagship tool and rankable task page. Validate query demand and competitor weaknesses; perform 100-file or suitable analogous product tests, not invented screenshots. A strong task is more valuable than 50 empty keyword pages.

### Search
Research exact user jobs, 12-month trends and country-level volume. Inspect SERP competition and feature click opportunity; target an intent cluster with a high-value page. Achieve technical crawl/index eligibility, then improve the actual user task and evidence. Track GSC nonbranded impressions and clicks, not only estimated keyword counts.

### YouTube and social
Produce an honest demonstration of an exact scenario: input, constraints, tool output and a downloadable result. Search title describes actual user problem. Link to the correct tool page; tag genuine referrals and measure task completion. Relevant YouTube clips may appear in Google, but views are not site visits.

### Developer/product-led distribution
If feasible, release a useful library, sample integration or widget with maintained documentation; users should be able to complete work without platform dependence. Respect code licenses. Referral links belong where they genuinely help, not a spam footer distributed to thousands of websites.

### Partnerships and communities
Answer actual questions on forums, educational sites, maker communities or editors when appropriate, with a relevant tested resource. Don't buy unnatural links, mass email irrelevant targets or post disguised ads. Track independent referrals and brand/navigation trends.

### AI citations
Publish original measurements and source-backed explanations, be crawlable and accessible, and monitor ChatGPT/Perplexity/Bing/Google AI mentions. Do not claim rankings or user acquisition from citation counts alone; measure actual link referrals and completed tasks.

### Retention
Add saved presets/recurring workflows only when users naturally repeat a job. Make output trustworthiness high. Encourage intentional return visits, not clickbait, notification spam or forced signup.

## Growth cycles
- Weeks 1–2: prove product quality and technical eligibility, collect baseline.
- Launch month: publish demos, contact a small relevant group, analyze first nonbrand impressions and real usage.
- 30/60/90-day review checkpoints: troubleshoot index → impressions → clicks → starts → completion → revenue, review evidence and costs. They are **measurement checkpoints**, not Google ranking promises.
- After traction: use known converting keyword intent to justify one adjacent distinct tool; keep one coherent topical domain.

## The financial constraint
Income = monetizable pageviews / 1000 × actual page RPM, adjusted for provider terms, consent, traffic quality and costs. AdSense qualification is not traffic; impressions are not visits; SEO CPC is not publisher RPM.
