**Date:** 2026-11-26. **Related:** [V34 Market Decision](DECISION.md), [V34 Product Specification](PRODUCT_SPEC.md), [V34 Evidence & Execution](EVIDENCE_AND_EXECUTION.md), [machine-readable V35 rows](../../../sources/image_tool_portfolio_v35.json). **Scope:** single category—browser-local **image compatibility, production and privacy**—on one coherent domain. **Status:** research candidate backlog, **NOT** 20 SEO-certified production pages.

## Important operating truth

We can build 20 tools but **cannot promise that 20 pages will be indexed, rank, or monetize.** Crawl eligibility, index inclusion, search impressions, real clicks, completed file tasks and AdSense approved earnings are separate evidence gates. The user requested each page to be in search; the honest implementable target is **20 distinct functional routes eligible for crawling**, with each route published/indexed **only if** its job, demand, unique benefit, output tests and current policy checks support it.

Original policy: [Google Search spam policies](https://developers.google.com/search/docs/essentials/spam-policies) explicitly cover scaled content/doorway abuse. [Google AI search guidance](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide) does not support special guaranteed AI-SEO formatting. [AdSense program policies](https://support.google.com/adsense/answer/48182) prohibit disguised ads and invalid interactions.

**Search-volume method:** Every number below is an approximate US monthly *search* estimate from Ahrefs, a secondary Keyword Planner-derived site or a vendor press release reporting Ahrefs—not authenticated Google Ads owner export, observed Search Console clicks, or realizable traffic. The same source may group close variants. Do not add these 20 numbers into a market total. Value of competitor feature pages != independent real file-output benchmark. UK, CA and AU exact volumes: **UNKNOWN**.

**Strongest directional original-data-methodology signal:** [GizmoBench September 2026 study](https://gizmobench.com/research/file-formats), using 191 DataForSEO-provided US Google Ads phrases for August 2025–July 2026, reports *sampled query searches to leave formats*: HEIC **343,700/mo**, WebP **316,950/mo**, AVIF **63,557/mo**. This is an aggregate **of the study's sampled queries**, not all demand, not user counts, not independent proof of product differentiation and not forecasted clicks. Its author also operates a web-tools site, a potential commercial incentive.

The pages are not automatically competitors of equal quality, and feature descriptions are **not observed output tests**.

## Portfolio architecture — 20 tools do not mean 20 clone pages

Only one site; one shared format detection, image inspector, safe decoder/encoder, orientation/ICC/metadata pipeline, Web Worker job queue, ZIP export, privacy controls and independent output oracle. Each route must do real work particular to its output. `/tools/heic-to-jpg/` serves HEIC→JPG; `/tools/image-compressor/` serves adjustable file-size reduction; `/tools/exif-viewer/` serves inspect-only privacy output. These **do not** all deserve separate indexing automatically merely because they have unique slugs.

**Potential intent cannibalization to resolve before indexing:** (a) HEIC→JPG vs HEIC→PNG, (b) JPG→PDF vs PNG→PDF vs generic Image→PDF, (c) Image Resizer vs Batch Image Resizer, (d) Image Color Picker vs Palette Extractor. Compare overlapping SERPs, audience and actual distinct controls. If user outcome is identical and only format/query labels differ, merge under one canonical route with query-param preselection and **noindex** duplicative URLs.

**Technical source proof:** Apple documents actual HEIF↔JPEG compatibility use; MDN documents format, animation, alpha, Canvas export and browser capability limits. Exact support must be tested on real Chromium/Firefox/WebKit and mobile. Some codecs and PSD/vector extraction require third-party packages with license/codec analysis, not unexamined CDN scripts. Never claim JPEG lossless if re-encoded, transparent JPG, perfect color matching, universal HEIC support or zero network uploads without real evidence.

## Search visibility contract per route

Each prospective page needs:
1. A dated per-country query and SERP receipt (Google results desktop/mobile, AI answers, top URLs, competing functionality, snippet and possible zero-click).
2. A successful **real downloaded output artifact**, including normal/invalid/boundary adversarial fixtures, compared with independent oracle; no toy buttons.
3. A unique human job, on-page immediately functioning tool, relevant format/method explanation, clear limitations and tested example output; not mass AI-written filler.
4. Server-rendered useful HTML (not just an empty client SPA), canonical, sitemap, internal link and 200 response on actual deployment, 404 on missing page, robots/noindex correct.
5. Accessible keyboard, mobile, screen-reader/error states, privacy-safe analytics, no misleading Ads/Download adjacency.
6. Real Search Console page indexation and query clicks monitored **after** deploy. An eligible page may never index or receive a click. Google is the final authority.
7. AdSense only after Google approval in owner's account; page RPM **UNKNOWN** until actual reporting. The aggregate keyword figures cannot be used to forecast net income.

## Build and validation sequence

**D0 BEFORE CODE:** 20 queries US plus GB/CA/AU, account-backed metric exports (if permitted), top 10 per country, strongest 3 competitors' same-file conversion outputs and a real 5–10-user task sample for first six; fail fast if no meaningful gap. Ahrefs connected account currently reports `Insufficient plan`, so do not impersonate a paid export. All 20 entries are **not yet independently proven winners**.

**Wave A — six compatibility tools:** HEIC→JPG, WebP→PNG, WebP→JPG, HEIC→PNG, AVIF→JPG, HEIC→PDF; shared architecture. First launch **two** completed routes and guides; expand to six only after real tests and observed user task demand.

**Wave B — eight productivity tools:** JPG→PDF, PNG→PDF, SVG→PNG, Image Resizer, Image Compressor, GIF Compressor, Batch Resize, Image Color Picker. Release route-by-route only where separate search intent exists.

**Wave C — six specialists:** PSD→PNG, EXIF Remover, EXIF Viewer, Palette from Image, Make PNG Transparent, Image→SVG. Some are lower-head-volume but add specialized use cases; each needs measurable reason to exist.

**Exit/halt criteria:** If incumbent passes all independent fixtures and users prefer its simpler free workflow, do **not** ship a duplicate. If new pages fail indexing quality review, consolidate instead of adding keyword permutations. If actual AdSense RPM, traffic and contribution don't justify maintenance, stop expansion; there is no promise all 20 pages will earn.
