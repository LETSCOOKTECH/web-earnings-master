# Portfolio operating model

**Do not multiply domains before proving economics and reusable acquisition.**

## Site manifest (one per property)
Origin/brand, purpose, distinct jobs, supported languages/countries, ownership/legal contact, privacy practice, ad network/IDs stored in secret manager, current verification gates, SEM/GSC/Bing account status, host, WAF/CDN, robots training/grounding policy, canonical policy, consent region handling, budgets.

## Monthly review
- Human sessions vs verified bots; source/medium and qualified acquisition by geography/device.
- Search impressions -> organic clicks -> tool starts -> success -> downloads -> returning sessions.
- AI citation presence/grounding topics vs actual AI-referred sessions (not equivalent).
- Google/Bing index health and dropped pages; top failing tasks; user complaints.
- Page RPM, geographic mix, eCPM, fill, ad-induced CWV regressions, invalid traffic alerts.
- Hosting/CDN/worker/codec costs, net unit economics, support burden.
- Decision: fix, expand, pause, or retire; document evidence and reviewer.

## New niche criteria
Measurable demand, multiple entry queries, user outcome, demonstrable product advantage or external distribution, usable low-cost stack, low abuse risk, repeat use where plausible, realistic lawful ads. Reject generic page factories.
