# 06 — Search-engine optimization / answer-engine optimization / generative-engine optimization

## Scope separation
SEO: increase eligible, relevant visibility and qualified referrals from web or vertical search engines.
AEO: informal industry label for being usable in answer-oriented experiences. Not a separate global standards authority.
GEO: informal label for generative answer discovery, citations and referrals. There is no unified rank or schema protocol across AI products.
ASO: discoverability and conversion in actual app stores; separate module 07.
Business outcome: qualified human task completion and net contribution, not any visibility vanity score.

## User-intent architecture (before HTML)
Define audience/locale, trigger, actual job, constraints, input, correct output and verification. Classify navigation, explanation, comparison, purchase, exact tool action, diagnostic, local and recurring tasks. Query terms are not equal to unique page requirements: multiple synonyms can map to one task/page; different jobs with different data/tool controls justify separate pages. Test live SERPs by region/device and record paid placements, AI answers, local packs, media panels and direct-answer zero-click conditions. Google Trends is normalized, Keyword Planner CPC is an advertiser metric, Ahrefs/Semrush demand and KD are third-party models. Do not manufacture per-query search volumes or organic click-through estimates.

## Technical eligibility
Secure domain and canonical host; DNS/TLS; correct HTTP 200/301/308/404/410; no soft-404; robots policy by crawler; meta robots/X-Robots-Tag; sensible canonical selection; indexable sitemap with real lastmod and only desired URLs; real anchor links; crawlable initial content for critical public pages; rendering parity; no unlimited parameter traps; useful hreflang only after actual translation; original and authorized media; accurate schema matching visible content; genuine mobile UX and measured CWV. Missing tools like GSC/Bing access -> say UNKNOWN. Never claim code-only pass is actual indexing.

## Content and product utility
Immediate job/answer, accurate title, descriptive intro and H1, clear method and tested examples, constraints and failure messages, honest authorship, version/source dates, privacy policy, navigable adjacent tasks. Serve real helpful output with reproducible tests. Do not add 1,500 words of filler or 100 near-identical size/format pages. Avoid scaled content abuse, site reputation abuse, expired-domain abuse, doorway networks and paid link schemes. E-E-A-T is Google's conceptual evaluation framework, not a disclosed site score. Third-party Domain Rating/Authority is not Google-issued.

## Ranking and candidate comparisons
Pick target SERPs where we can demonstrate a better *user job result*, not just a lower DR competitor. Compare intent, actual product reliability, measured completion time/steps on same authorized fixtures, supported formats, trust/source transparency, mobile and accessibility. A #1 rank is query/context specific and is not reproducibly guaranteed from a meta checklist. An established brand's navigational query is generally a poor acquisition target for newcomers; an answer-only SERP may earn little outbound traffic. Use expected obtainable clicks and real completion, not broad search volume.

## Organic authority and distribution
Original research, independently useful tools, developer integrations, free samples, transparent benchmarks, educational materials, relevant community participation and honest editorial outreach can produce referrals and earned links. No automated profile backlink spray, purchased followed links, made-up citations, bot CTR manipulation or PBN. Distinguish actual editorial link from a self-created submission.

## 2026 AI search considerations
Google explicitly says standard Search SEO practices apply to its generative features; it says special llms.txt, Markdown AI text files, artificial chunking and mass inauthentic mentions are not required or helpful to its Search rankings. Non-Google providers may consume machine-readable material differently; investigate and test individually. Publish original reason-to-cite data; verify links, robots, citation appearance and real referred humans. OAI-SearchBot permission differs from GPTBot training; Google-Extended purpose differs from Googlebot; Perplexity-User may fetch despite robots instructions. AI answers may suppress clicks, so do not price website traffic as all query searches.

## Real production operating loop
Demand + SERP sample -> site spec with user job -> build useful public HTML and functioning tool -> automated & manual QA -> Search Console + Bing property ownership -> verify index/crawl/live URL -> gain qualified referral sources -> monitor impressions/clicks/starts/completions/retention -> experiment on observed weakest stage -> publisher compliance and net income -> stop, repair or expand. A new domain has no guarantee of impressions by a chosen deadline.

## SEO false-positive triage
"200 + canonical" is insufficient if CDN blocks bots; "indexed" insufficient if no matching queries; "rank 1" insufficient if brand navigational or AI zero-click; "many citations" insufficient if no human sessions; "good RPM" insufficient if traffic invalid; "passed AdSense checklist" is not actual provider approval.
