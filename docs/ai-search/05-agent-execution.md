# 05 — Autonomous agent AEO/GEO execution gates and output

## Scope gate
Name actual target site, public URL, operator, countries/languages, user job and intended product (Google AI Mode, Bing AI Performance, ChatGPT Search, Claude, Perplexity, conventional answer surface or agent browser). A generic request to dominate all LLMs has no defined score: split into provider/mode-specific tests.

## Evidence gate 0 — official first-party source
Read docs/seo-master/08-live-source-verification-v13.md and sources/ai_search_v14_surface_atlas.json. Reopen relevant original source, save section/access date, distinguish direct opened from search excerpt, country/account and effective date. Review latest Search Central and vendor blog updates. Block claims when doc 403/429, outdated or contradictory. Source hash and URL are not semantic truth.

## Gate 1 — human need and useful answer
Collect real user question and task output, independent source/knowledge, original methodology, accurate direct answer/context and actual functional tool. Block generic copied FAQ walls and AI fanout keyword-doorway farms. AEO owner web-aeo-answer-optimization.

## Gate 2 — search technical and provider crawler policy
Owner web-ai-discovery + web-crawler-governance + web-technical-seo. Verify real HTTP, initial HTML, canonical, intended indexed/snippet state and Google Search property inclusion; actual robots groups per search crawler and independent training/user-initiated preferences. No modifying owner crawler/training preferences without consent. An offline allowed flag is insufficient: check deployed CDN/WAF and provider identity. Run scripts/audit-ai-eligibility-v14.mjs on a built site for **LOCAL constraints only**.

## Gate 3 — independent claim and action correctness
Owner AEO + product validation. Original source fact/quote ledger and currentness, counterevidence, answer usefulness, actual code/file correctness and edge-case mutants. Structured data must match visible truth; no AI-only markup requirement. Make human readable source even without JS. Negative tests must break intentionally incorrect claims/hidden content.

## Gate 4 — first-party reporting and bounded observation
Owner web-generative-engine-optimization + web-search-analytics. Query owner GSC URL Inspection and GenAI report if property feature actually available; Bing AI Performance/Topics beta only when owner can see them. For ChatGPT, Claude, Perplexity run authorized fixed prompt samples and record visible source links separately from mentions/retrieval. Add actual human referral/task counts from privacy-safe analytics. Do not transform observed percentage into world market AI visibility.

## Gate 5 — experimental improvement
Choose one real defect: indexed but excluded, blocked bot, weak direct answer, misleading caveat, broken output, non-original copied content, poor agent labels or high bounce. Fix and rerun negative tests plus same prompt panel; track timing, search rollout and competing explanations. No unauthenticated external bot impersonation or spam backlinks.

## Gate 6 — publisher and business economics
Verify legit humans and correct tool outputs, regional consent, AdSense page/account policy and actual net revenue after costs. Citation not pageview; sponsored ad click not validated as human; don't use keyword advertiser bids as publisher RPM. No fake source reviews or model manipulation.

## Agent dispatch
AEO: web-aeo-answer-optimization and web-product-validation.
GEO: web-generative-engine-optimization + web-ai-retrieval-lab + web-ai-discovery.
Crawler/technical: web-crawler-governance + web-technical-seo.
Agent UX: web-accessibility-agent-ux + web-browser-runtime.
Analytics: web-search-analytics + web-experiments.
Use smallest subset necessary; do not inject entire 48 skills for one question.

## Deliverables
Provider mode and exact source (original opened vs lead), permissions, public URL, query sample/prompt panel, dated observation per provider/product, supported user answer and test fixture, crawler/snippet/owner inclusion state, offline/real-browser/live evidence, independent citations/real referrals/task and revenue metrics, negative mutants, uncertainty, counterevidence, GO/HOLD/BLOCK and next cheapest test.

## Hard invariant
Local CI can show correct agent guidance and local website eligibility checks. It cannot certify Google index selection, Search Console owner setting, actual AI citation, provider response quality for all prompts, ad approval or profit. Any missing external observation stays UNKNOWN, never 10/10 global AI search dominance.
