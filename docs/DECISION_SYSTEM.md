# Decision gates — applied to every domain

| Gate | PASS evidence | Failing condition |
|---|---|---|
| Market | Country/device-specific search estimates, recent trend, relevant searcher job, SERP audit | No verified task or no viable discovery channel |
| Competition | At least five real workflow tests with reproducible fixtures; real advantage or distribution route | Clone with no defensible difference |
| Functionality | Unit/E2E/mobile device evidence, real output validation, accessible errors | Known unhandled corrupt outputs or broken core task |
| Policy | Current AdSense/other network docs mapped to pages, privacy + consent assessed | Deceptive ads, thin pages, invalid traffic, unverified publisher identity |
| Technical | Build output and live HTTP correct, noindex/canonical/sitemap/robots tested, WAF allowed verified crawlers | Critical pages unreachable or not indexable |
| Trust/content | Actual examples, help, privacy, contact and operator truthfulness | Fake testimonials, scraped/filler content, fabricated experiment |
| Acquisition | Search Console/Bing connected; human referral channel executed; conversion event telemetry | Only vanity impressions without real tasks |
| Economics | Observed geography, fill, page RPM/eCPM, net income and hosting/cost | Monetization reduces trust or economics are negative |

**GO only with evidence** recorded in `templates/release-evidence.md`. Never turn missing data into a green checkbox.

## Priorities for the first site
Sense Image Tools on one Astro domain: four related free tools, zero server image processing for supported file types, original workflow evidence, dedicated task pages, no parameter-spam pages, conservative ads. Alternative niches must pass the same market gates rather than bypassing them.
