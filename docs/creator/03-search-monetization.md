# SEO, AEO/GEO, referral traffic and legitimate publisher economics

Prerequisite: a genuinely functioning tool and, before real ranking measurement, an owner-authorized publicly deployed HTTPS URL. A reserved example.org canonical is documentation metadata only.

First ensure HTTP and crawler controls on the real served route, original helpful HTML, robots/noindex/X-Robots correctness, final-hop canonical, responsive UX, secure user task, sitemap and contextual internal links. Verify signed-in GSC/Bing property data, actual indexing and time/locale query impressions when available. Never equate static eligibility with actual index placement.

Measure provider products separately: Google AI Overviews vs AI Mode vs Gemini; consumer ChatGPT Search vs OpenAI API search; Perplexity Web vs API; Bing/Copilot and Claude web search. Preserve raw authorized answer, provider/version, locale, country, observed date, unbranded task, negative/unavailable attempts and actual citation. Citation, mention, positive endorsement, ordered top position, clicked referral, and completed task are distinct metrics. No unknown engine's weights can be guaranteed.

Sustainable traffic: source-backed examples, original test results, genuine integration/use-case referrals and earned community discussion with permission. Reject spam, fake recommendations, keyword doorway generation and prompt injection in agents. Human task completion and retention matter more than vanity impressions.

AdSense or any other ad network: only actual owner account eligibility and policy-compatible original value. No ad pretending to be a download, no invalid click incentives, privacy/consent and geography reviewed. Model real publisher proceeds minus infrastructure/compute/support cost; don't multiply guessed RPM by artificial traffic.
