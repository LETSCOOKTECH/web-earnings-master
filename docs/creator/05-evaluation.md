# How to prove a creator skill improves agents

Software correctness and skill effectiveness are separate. Passing one starter's own published tests does not show that a general agent will complete unknown user tasks or rank in search.

Prepare five previously unseen user jobs across deterministic data, image processing, precise calculator, authenticated API and bounded AI conversion. For each define task, constraints, independently held-out input/output oracle, malformed/security cases, mobile/keyboard reviewer, exact code/compilation, deploy restrictions and cost. Do not show the grader to the agent.

Run same model and effort with equal tool permissions/budget/time across (A) Sense orchestrator, (B) no master orchestrator, optionally (C) a lawful external workflow such as Croftweaver. Shuffle task order, capture actual logs/commits/screenshots/download bytes and blinded reviewer scores. Keep all failures and unverified tasks in denominator. Measure completed primary tasks, security failures, accessibility defects, hallucinated demand, retry/rework, time and spend. Do not translate 5 tasks into a proof of a universal effect size.

External business outcomes require actual owned public website, owner Search Console/Bing, authorized AI answers and publisher/traffic accounting. A synthetic demand JSON can be structurally valid and still completely invented. Run npm run test:creator for fail-closed manifest checks, actual clean Astro CI and the full repository npm test. Report NOT_RUN separately from PASS. No fabricated 100x label.

Reference source: https://developers.openai.com/blog/eval-skills ; https://agentskills.io/specification .
