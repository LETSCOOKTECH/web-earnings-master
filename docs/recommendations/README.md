## Necessary distinctions

A page being crawlable does not prove indexing. Indexing does not prove it was consulted. A visible citation is not a product endorsement. A brand mention is not a positive recommendation. A recommendation is not necessarily ranked. First in a list on one prompt is not #1 globally. Model search, consumer conversational search, API web search, partner feeds, shopping, news, local and user-initiated browser agents may select different data sources.

## Minimum meaningful evidence

Independent users successfully complete a task; honest competitor benchmark shows when to prefer the tool; accessible crawlable initial HTML and privacy-safe processing; first-party owner reports; provider screenshots or permitted outputs with dates, countries and model product; preregistered repeat answers preserving unavailable and unfavorable outcomes; direct evidence of attributed citations; real humans and conversions measured separately. Without that, HOLD, not production rank certification.
