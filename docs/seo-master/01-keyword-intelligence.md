# 01 — Advanced keyword research and honest on-page placement

## The 10-step decision loop
1. Define target human, geo/language/device, real task, exact inputs/outputs, urgency, current substitutes, supported variants and objective success fixture.
2. Form a small seed matrix of action, input, desired output, format/size/privacy limits and local workflow language. Hypotheses are unmeasured until research.
3. Inspect permitted real Google SERPs in target country/device: organic results, ads, AI answer, images/videos, trusted tools, brand domination, actual click friction. Save date and URLs.
4. Use approved Google Trends UI/CSV for relative interest 0–100 (same term/topic/time/geo/search-type comparison context). Zero can mean low-volume sampling; graphs with different denominators cannot simply be compared.
5. Use authorized Keyword Planner for **estimated** monthly search volume, advertiser competition and bids, not organic difficulty. Semrush/Ahrefs are licensed **modeled** volume/KD and competitor traffic, not Google internal ranking weights. Owned GSC/Bing provide only their own property observations.
6. Collect independent allowed original user problems/competing alternatives and small real tests. Reddit profiles aren't identity-verified users; multiple reposts don't equal independent demand.
7. Cluster queries by the **same actual job**. One URL can cover synonymous queries when one working user flow satisfies them. Separate URL only for distinct output/user intent with its own functioning fixture and useful original content.
8. Compare competitors with identical input and objective output. Assess distribution, workload cost, accessibility/privacy and whether the SERP/AI answer leaves a viable human click opportunity.
9. Draft URL brief with primary user query, secondary helpful concepts, canonical path, natural title/H1, visible how-it-works, inputs/outputs and limitations, proof fixture, links, source evidence and monetization constraints.
10. Deploy a small pilot and revise based on actual GSC country/query/page impressions and clicks, valid task successes, support pain and unit cost. Never claim Google ranking from keyword frequency or high KD score.

## On-page rules
- Accurate clear unique title and main heading describe the user job. One H1 is a useful project convention, not a Google requirement for exactly one.
- First visible explanation says what tool does and does not do. Original worked examples and supported constraints matter more than an arbitrary number of words.
- Meta description is a snippet proposal, not a ranking multiplier; Google may use different text. Do not generate a meta-keywords tag for Google Search (ignored).
- Natural descriptive links and relevant task-specific images alt. Do not add repeated exact-match anchors, invisible city lists, unrelated synonyms or keyword dumps.
- URL keyword is a navigation convenience, not an automatic PageRank/AI citation boost. Structured data must match visible content and an actually eligible current rich result type; no fabricated review/FAQ tactics.
- Published pages should deliver the advertised functionality. A fake converter pointing to ads may violate Search spam policy.

## Evidence ledger fields
query, geo, language, device, search_type, date/window, original URL, actual source access method, metric and unit, observed/estimated/normalized class, screenshot/CSV hash when generated, user_job, intent cluster, SERP competitors and features, page URL, uncertainty, contradictory source and independent validation. No claimed volume from a sample keyword map.

## Hard stop
Unapproved automated Google scraping, fabricated first-party search metrics, Trends 100 treated as searches, advertiser CPC treated as AdSense RPM, duplicate-URL keyword farms, misleading functionality, missing real output, keyword-stuffed text or no measurable user need.
