# V12 Mandatory agent pipeline: real keyword opportunity to working site

## Research without wasting credits
First identify a precise human job, the geographical market, actual work inputs and outputs, a deterministic output oracle, existing alternatives and the least-cost experiment to falsify demand. Use web-opportunity-intelligence with actual permitted browser tool availability. Record original Google Trends CSV or Google Keyword Planner/Semrush/Ahrefs estimates only when truly accessed; these metrics have distinct measurement models and are not interchangeable. Public Reddit discussion is not independent proof of verified human identity.

Keyword mapping means one distinct working task per useful canonical page. Synonymous keywords doing the same operation share a page. Natural title/H1/intro/body/links reflect actual tested features. Do not publish keyword-stuffed, AI-scaled doorway, fake geo variants or fake download pages. Google Ads advertiser competition and CPC cannot establish Google Search rank or AdSense RPM; AdSense is a separate publisher policy system.

## Implementation and proof
1. Start with the shipped core and objective fixture, not decorative tool marketing.
2. Choose static/browser-local or bounded API/DB/worker by real workload, security and cost.
3. Build initial HTML discoverable without JS and functional controls with accessible feedback, privacy and correct downloadable outputs.
4. Run unit and adversarial tests of actual code, including data corruption, malformed and oversized input, formula safety, low-memory limits and no unexpected network calls.
5. Verify actual crawler-specific robots rules, current official Search spam/technical requirements, canonical, indexable sitemaps and local JS/CSS asset references.
6. Run actual shipped UI Playwright in Chromium/Firefox/WebKit; deliberately break JS to demonstrate negative detection. Browser emulation is not proof of real mobile hardware.
7. Deploy only with owner authorization to separate HTTPS staging, secure headers, monitoring, rollback and real-site HTTP tests; never copy synthetic example.org canonicals to production.
8. Google Search Console indexing, human search clicks/valid tasks, AdSense owner account approval and revenue need their own connected account evidence and cannot be claimed from offline JSON flags.

- scripts/audit-live-site.mjs: separate actual authorized HTTPS, project-specific nonfixture route manifest.
- tests/seo-csv-browser-e2e.mjs: real owned-browser JS and bytes, no private account.
- docs/seo-master/05-independent-observatory-v12.md: ten controlled local quality criteria.

## Reporting
For each gate return PASS_LOCAL, FAIL or UNKNOWN_EXTERNAL with date, exact source, tool execution, artifact hash and contrary evidence. Stop for genuine blockers. A full green laboratory can earn 10/10 on its explicit local criteria, never 10/10 Google ranking dominance. Reopen official first-party source body before material policy decisions and compare account/geo/effective status rather than blindly using old links.
