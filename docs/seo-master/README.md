## Route and release sequence
1. **User opportunity:** web-opportunity-intelligence → exact human user job, geographical market, observed public problem, cost, alternatives and weakest hypothesis. Do not use paid API/Computer Use without confirmed tool, owner and provider authorization.
2. **Keyword discovery:** web-keyword-intent → controlled Google Trends, licensed Keyword Planner/Semrush/Ahrefs, owned GSC, real geo/device SERP. Record what was actually opened/exported, dates, region, absolute vs relative vs modeled metric and uncertainty. Do not fabricate volumes.
3. **Keyword-to-page design:** one unique working input/output task per canonical indexable URL. Synonyms sharing a user job share a page; keyword-swapped doorway pages are forbidden. Prepare natural title, H1, summary, limits, evidence, correct alt and contextual links before coding.
4. **Build:** web-workload-architecture-router → web-fullstack-production-executor, frontend/backend skills. Choose minimal browser-local, static, SSR, backend, worker, DB and storage by real workload/cost/privacy; never prescribe Astro to improve rank magically.
5. **Verify task:** web-product-validation requires real deterministic output bytes/files, malformed/oversized cases, accessibility, privacy, browser/device correctness, negative fixture detection. Passing static SEO audit cannot prove that a tool works.
6. **Verify Search:** web-technical-seo checks real HTTP/DNS/TLS, status/redirect/404, initial and rendered HTML, canonical, robots/noindex, sitemap, link graph, supported schema, mobile CWV; external owner GSC is separately required for indexed state.
7. **Publisher:** web-publisher-policy-eligibility and web-ad-experience check site/account eligibility, original value, ad placement, invalid traffic, consent and real approval. Never deploy real ad units to a misleading/broken/unauthorized page.
8. **Launch:** web-launch-review and web-release-observability-operator verify deployed host, headers, staging, secrets, rollback, incident plan, cost ceilings and real production URLs.
9. **Measure:** web-search-analytics and web-traffic-hunter distinguish impression, indexed, query click, AI citation, referral, valid task completion, eligible pageviews and actual revenue. No inferred causal rank weights.

## Mandatory source distinctions
**Google Search** governs SEO and spam. Google Search ignores meta keywords; no official keyword density or magic word count; stuffing and scaled pages without value violate spam guidelines. **Google Ads Keyword Planner** reports advertiser-oriented volume and competition/bids; these are not organic KD or AdSense publisher RPM. **AdSense** has distinct publisher/ad-placement/invalid-traffic policies, not a magical SEO keyword rule.

## Evidence ladder
SOURCE_LEAD → ORIGINAL_FIRST_PARTY_BODY_INSPECTED → LOCAL_CODE_PASS → REAL_BROWSER_FUNCTION_PASS → HTTPS_STAGING_PASS → LIVE_SITE_PASS → OWNER_GSC_INDEXED → VERIFIED_HUMAN_TASKS → PUBLISHER_ACCOUNT_APPROVED → RECONCILED_REVENUE. These are separate claims. A manifest containing self-declared PASS values cannot establish the external tiers. All unobserved states remain UNKNOWN_EXTERNAL.

## Completed local demonstration
A separate six-page CSV deduplicator website was generated in a sandbox using an original pure JavaScript CSV implementation. 22 Node output tests and 32 Python static/HTTP tests passed; adversarial SEO mutations were detected. Real Chromium browser navigation was blocked by administrator policy. No external indexing, ranking, live website or account approval was tested. Do not call the lab a full production release, and do not assume a local PASS transfers to a different website. The complete sample website/test package is available as a conversation download.

## Production gate
Run the existing repository CI and the actual project's build/output/browser/integration tests. Require live HTTPS and owner-account evidence before claiming production readiness. This handbook is an execution specification and evidence quality standard, not an automatically enforced law for all projects until the project adopts it.
