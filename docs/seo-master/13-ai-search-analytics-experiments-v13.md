# V13 — AI discovery, Search Console, real traffic and controlled experimentation

Owners: web-ai-discovery, web-generative-engine-optimization, web-ai-retrieval-lab, web-search-forensic-evidence, web-search-analytics, web-experiments and web-traffic-hunter. Atlas categories SEARCH_DISCOVERY and KEYWORD_RESEARCH.

## Treat each product as separate
Google ordinary organic results, AI Overviews, AI Mode, Gemini, ChatGPT Search, OpenAI API web search, model training GPTBot, OAI-SearchBot, Claude Search, Perplexity and Bing do not share one revealed ranking formula. Crawled != indexed != cited != human click != completed task != return != net publisher revenue. Do not market a single fake "AI visibility" score across incomparable sources.

## Google AI Mode and Overviews
Google's published AI Search guide says a supporting URL must be indexed and eligible for a Google Search snippet. Established Search technical and helpful content principles apply; no special AI schema, llms.txt file or artificial chunk size is required. Query fan-out can retrieve multiple subtopics but does not validate doorway spam across synthetic queries. Source selection remains opaque and non-guaranteed. Use [Google AI features](https://developers.google.com/search/docs/appearance/ai-features) and [AI optimization guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide); reopen current first-party body and effective date.

## Other model/search providers
For each target provider inspect separately bot role/search/training/user fetch, robots and actual WAF/CDN access, official published crawler documentation and account/product control. Search crawler access is not training permission. See [OpenAI crawler documentation](https://developers.openai.com/api/docs/bots). Do not assume a GPTBot allowlist guarantees ChatGPT Search mentions; nor is an agent-only API necessary for Google rankings. Agent-friendly accessible semantic actions benefit users but need separate task testing and provider evidence.

## Observing AI citation
Choose prompts from actual human user jobs, not synthetic search-tail phrases manufactured to inflate apparent visibility. Record provider/product/version, date/geo/language/account/search mode, prompt group, repeated trials, actual visible supporting source URLs, resolved page URL and source context, competitor contrast, displayed citation versus background retrieval, real human referrals and completed tool actions. No model claim without actual source observation; no automatic citation -> revenue inference. Check reruns, personalization and answer layout changes.

## Search Console and first-party funnel
Owner GSC property is required for real page indexing and Search performance. Distinguish URL Inspection indexed snapshot from live fetch. GSC dimensions: date, country, device, page, query, search type, impressions, clicks, CTR and average position with privacy/anonymized query gaps and reporting lag. Search Analytics API has row limits; group-by and filtering are not complete market-wide counts. The Google AI Search documentation describes AI search visits inside overall Search Console Web performance; do not assume an independent universal AI-only report without direct product evidence.
First-party privacy-respecting task funnel: eligible landing -> tool view -> input accepted -> task success/fail -> verified output/download -> return user -> valid ad opportunity -> provider net revenue. Avoid logging private filenames or raw content.

## Experiment discipline
Record a falsifiable hypothesis, target cohort, exact page/query/device/country, prior baseline window and change date, source update or algorithm event, seasonality, concurrent marketing campaigns and competing alternatives. Prefer controlled tests or carefully qualified before/after, inspect credible size and uncertainty; don't call a rank movement of one query causally proven by a title change.
Diagnosis: no crawl -> HTTP/robots/WAF/link graph; crawled not indexed -> canonical/quality/duplication; indexed no impression -> relevance/demand; impressions low CTR -> SERP intent/snippet; clicks no task starts -> UX; starts no finish -> functionality; completes no return -> need; real users no profit -> ads/account/geo/economics. Stop at cheapest decisive root-cause test, not generic SEO busywork.

## Reporting
Per experiment: provider/search mode; dated observed original URL and source; actual platform access method and permissions; region/device; actual baseline numbers and units; treatment/control and confounders; live traffic/task events; interpretation, limitations, rollback and next test. Never conflate Google Ads CPC with publisher RPM, third-party estimated site traffic with owner sessions, or ai citations with visits.
